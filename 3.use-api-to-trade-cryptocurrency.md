## How to use CCXT module to trade automatically

* To install CCXT in python, just type `pip install ccxt` in command lines
* Sample codes: APItrade.py

```
import ccxt
ftx = ccxt.ftx({
    "apiKey": "YOUR ACCESS KEY",
    "secret": "YOUR SECRET KEY"})

# Buy 100 Dogecoin at the market price
order = ftx.create_market_buy_order(symbol='DOGE/USD', amount=100)
print(order)

# Sell 100 Dogecoin at the market price
order = ftx.create_market_sell_order(symbol='DOGE/USD', amount=100)
print(order)

# Buy 100 Dogecoin at the price of 0.1
order = ftx.create_limit_buy_order(symbol='DOGE/USD', amount=100, price=0.1)
print(order)

# Sell 100 Dogecoin at the price of 0.15
order = ftx.create_limit_buy_order(symbol='DOGE/USD', amount=100, price=0.15)
print(order)
```

## (2) Use API to get price information and do backtest in quantitative trading



## How much money I can make?

Suppose you have a simple buy and hold strategy, you buy $1000 dollar worth of Bitcoin every week since 01/08/2019, how much money you can make or loss until now?



To fugire this problem we have three simple steps:

* Get weekly price from 01/08/2019 until 10/03/2022
* Calculate how much Bitcoin we bought every week
* Calculate the current market value of the Bitcoin

## (1)Get weekly price

Following FTX Api documentation, we can use `get_historical_price`function to get the weekly price from 01/08/2019 to 10/03/2022

Please Prepare 2 files in your folder:

* FTXsample.py
* Backtest.py

Just open Backtest.py

```
from FTXsample import FtxClient
import time
import datetime

# Create account
# Market Information does not need Api key
ftx = FtxClient(api_key='', api_secret='')


# Convert time into timestamp
def ts(date):
    return time.mktime(datetime.datetime.strptime(date, "%d/%m/%Y").timetuple())

        
# Get bitcoin price data
btc_data = ftx.get_historical_price(market='BTC/USD', 
                                    resolution=432000, 
                                    start_time=ts("01/08/2019"),
                                    end_time=ts("10/03/2022"))
print(btc_data)
```

## (2)Back test

To calculate how much bitcoin every week, simple use the amount we invested everyweek, which is $1000, divided by the price of the Bitcoin, suppose we buy at the highest price in the week!

Then, to calculate how much money we make, we need to compute the market value of all the Bitcoin we have, then minus all money we have invested.

```
buy_btc = 0
# The amount we invested each period
fiat_amount = 1000
period = 1


for i in btc_data:
    buy_btc_today = round(fiat_amount / i['high'], 6)  # bitcoin amount we buy = amount / price    
    buy_btc += buy_btc_today  # total bitcoin we bought until now    
    total_amount = period * fiat_amount  # total money we invested = number of weeks * money we invested each week    
    average_price = int(total_amount / buy_btc)  # average price = total money we invested / total bitcoin we bought    
    market_value = i['high'] * buy_btc  # currency bitcoin market value = amount * price    
    profit = market_value - total_amount  # profit = market value - total amount we invested    
    
    print('period %s, buy %s bitcoin, total bitcoin we buy: %s, total amount we invested: %s, average price %s, profit %s'        
    % (period, round(buy_btc_today, 6), round(buy_btc, 6), total_amount, average_price, int(profit)))    period += 1
```

If we buy $1,000 dollar worth of Bitcoin every week since 01/08/2019

* We totally invested $191,000 dollar,
* We bought 12.1018 Bitcoin at an average price of $15,782 each Bitcoin,
* The market value until now is $515,863,
* Our profit is <mark style="color:red;">**$324,863**</mark> in around 3 years!
